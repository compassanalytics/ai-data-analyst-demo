# Frequently Asked Questions

## General Questions

### What is this platform?

Our platform is a unified data intelligence solution that enables teams to collaborate on analytics, reporting, and AI-powered insights. It connects to your existing data sources and provides intuitive tools for data exploration, visualization, and sharing.

### Who is this platform for?

Our platform is designed for:
- **Data Teams**: Analysts, engineers, and scientists who work with data daily
- **Business Users**: Marketing, sales, finance, and operations teams who need insights
- **Executives**: Leaders who need dashboards and reports for decision-making
- **IT Teams**: Administrators who manage data governance and security

### What makes this platform different?

Key differentiators include:
- **AI-Powered Insights**: Natural language querying and automated insights
- **Unified Platform**: Analytics, reporting, and collaboration in one place
- **Enterprise Security**: SOC 2, HIPAA, and GDPR compliant
- **Flexible Deployment**: Cloud, on-premises, or hybrid options
- **Extensive Integrations**: 100+ pre-built connectors

## Technical Questions

### What data sources do you support?

We support 100+ data sources, including:
- **Databases**: PostgreSQL, MySQL, SQL Server, Oracle, MongoDB
- **Data Warehouses**: Snowflake, BigQuery, Redshift, Databricks
- **Cloud Services**: Salesforce, HubSpot, Google Analytics, AWS
- **Files**: CSV, Excel, JSON, Parquet

See our full connector list at docs.company.com/connectors.

### How does data sync work?

Data can be synced in multiple ways:
- **Real-time**: Changes reflected immediately (supported sources only)
- **Scheduled**: Sync at specified intervals (hourly, daily, weekly)
- **Manual**: On-demand sync when needed

You can configure different sync strategies per data source.

### Can I use SQL to query my data?

Yes! Our platform supports full SQL querying with:
- Standard SQL syntax
- Auto-complete and syntax highlighting
- Query history and saved queries
- Parameterized queries
- Query scheduling

### Do you have an API?

Yes, we offer a comprehensive REST API that allows you to:
- Query data programmatically
- Manage users and permissions
- Create and update dashboards
- Export data and reports
- Integrate with your workflows

API documentation: api.company.com/docs

Yes, security is our top priority:

Data is stored in secure cloud infrastructure:

### Can I delete my data?

Yes, you have full control over your data:
