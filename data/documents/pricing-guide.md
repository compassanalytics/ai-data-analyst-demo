# Pricing Guide

## Overview

Our pricing is designed to scale with your needs. Whether you're a startup or an enterprise, we have a plan that fits your requirements and budget.

## Pricing Tiers

### Starter Plan - $29/month

Perfect for small teams getting started with data analytics.

**Includes:**
- Up to 5 users
- 10 GB data storage
- Basic analytics features
- Standard data connectors
- Email support
- Community forum access

**Limitations:**
- No custom dashboards
- No API access
- No SSO integration
- Standard retention (30 days)

### Professional Plan - $99/month

Ideal for growing teams that need advanced analytics capabilities.

**Includes:**
- Up to 25 users
- 100 GB data storage
- Advanced analytics features
- All standard connectors + premium connectors
- Custom dashboards
- API access
- Priority email support
- Live chat support

**Additional Features:**
- SSO integration (additional $20/month)
- Extended retention (1 year)
- Scheduled reports
- Basic workflow automation

### Enterprise Plan - Custom Pricing

For organizations requiring enterprise-grade features and support.

**Includes:**
- Unlimited users
- Unlimited data storage
- All features from Professional
- Advanced security features
- Custom integrations
- Dedicated account manager
- 24/7 phone support
- On-site training
- SLA guarantees (99.9% uptime)

**Enterprise-Only Features:**
- SAML/OIDC SSO included
- Custom data retention policies
- Multi-region deployment
- Advanced audit logging
- Customer-managed encryption keys
- Dedicated infrastructure option

## Frequently Asked Questions

**Can I switch plans at any time?**
Yes, you can upgrade or downgrade at any time. Changes take effect immediately, with prorated billing.

**What happens if I exceed my user limit?**
You'll receive a notification and have 7 days to either upgrade or remove users.

**Do you offer discounts for nonprofits?**
Yes, we offer 50% off for registered nonprofits and educational institutions.

**Is there a discount for startups?**
Yes, qualifying startups can receive up to 90% off for the first year. Apply through our startup program.
